# Sales Management System

## Project Overview
A sales management web application built using Python, Streamlit, and MySQL.

## Features
- User login with Super Admin and Admin roles
- Multi-branch sales management
- Customer sales records
- Payment tracking and payment splits
- Automatic received and pending amount calculations
- Dashboard and sales reports
- Branch, product, and date filters
- CSV data import

## Technologies Used
- Python
- Streamlit
- MySQL
- SQL

## Database Tables
- `branches` — branch details
- `users` — user information and roles
- `customer_sales` — sales records
- `payment_splits` — payment transactions

## How to Run
1. Install Python and the required libraries.
2. Set up the MySQL database and tables.
3. Configure database credentials securely.
4. Run the application with `streamlit run app.py`.

## Security
Never publish database passwords or private customer data.
